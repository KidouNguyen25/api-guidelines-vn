# Microsoft REST API Guidelines
Cảm ơn bạn đã quan tâm đến Microsoft REST API Guidelines. Nếu bạn đã đến được đây, có lẽ bạn đang muốn tìm hiểu về API. Nếu vậy, bạn đã đến đúng nơi!
Chúng tôi công bố các hướng dẫn này tại đây nhằm thúc đẩy đối thoại và học hỏi trong cộng đồng API nói chung. Chúng tôi cũng hy vọng các hướng dẫn này có thể khuyến khích các tổ chức khác xây dựng những hướng dẫn phù hợp với mình và, nếu có thể, công bố chúng.

### Hướng dẫn cho các nhóm dịch vụ Azure
Các nhóm dịch vụ Azure nên tham khảo các tài liệu đi kèm, [Azure REST API Guidelines](./azure/Guidelines.md) và [Những điều cần cân nhắc khi thiết kế dịch vụ](./azure/ConsiderationsForServiceDesign.md), khi xây dựng hoặc chỉnh sửa dịch vụ của mình. Các tài liệu này cung cấp một bộ hướng dẫn đã được tinh chỉnh, nhắm riêng đến các dịch vụ Azure. Để biết thêm thông tin, vui lòng tham khảo [README](./azure/README.md) trong thư mục Azure.

### Hướng dẫn cho các nhóm dịch vụ Microsoft Graph
Các nhóm dịch vụ Graph nên tham khảo tài liệu đi kèm, [Microsoft Graph REST API Guidelines](./graph/GuidelinesGraph.md) khi xây dựng hoặc chỉnh sửa dịch vụ của mình. Tài liệu này cùng với danh mục mẫu thiết kế liên quan cung cấp một bộ hướng dẫn đã được tinh chỉnh, nhắm riêng đến các dịch vụ Microsoft Graph.
