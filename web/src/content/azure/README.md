# Hướng dẫn Azure REST API
Khi xây dựng các thành phần phần mềm mà nhà phát triển sẽ dùng để xây dựng phần mềm khác, việc cung cấp những API dễ sử dụng, phù hợp mục đích, có khả năng mở rộng, dễ bảo trì và nhất quán trong toàn bộ sản phẩm có thể tạo nên sự khác biệt giữa thành công và thất bại cho phần mềm của bạn. 

Thiết kế những API mạnh mẽ với các giá trị mặc định tốt, hành vi nhất quán giữa các dự án liên quan và dễ sử dụng đối với nhà phát triển bắt nguồn từ việc đặt mình vào vị trí của người dùng giao diện của bạn và quan tâm thực sự đến những mối bận tâm của họ. Các API bạn phát hành có thể ảnh hưởng rất lớn về lâu dài đến sức khỏe của sản phẩm phần mềm, và đó là lý do **REST API Stewardship Board** có mặt để giúp bạn! Chúng tôi đã công bố một tập hợp các thực hành tốt nhất, hướng dẫn REST và hướng dẫn phong cách OpenAPI để giúp bạn tạo ra trải nghiệm tuyệt vời cho nhà phát triển.
